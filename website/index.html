✓ Android — hadda waa la heli karaa

Soo deji APK-ga tooska ah

Faylka waxaa si toos ah uga soo deji karaa boggan: babelish.apk, oo lagu saxiixay debug-key (v1 + v2 + v3) oo tijaabo toos ah loogu talagalay. Ma aha ZIP, mana aha artifact Actions. Google Play lama gelin karo; Play Store-ka waxaa loo isticmaalaa AAB saxiixan.

Soo deji babelish.apk Dhammaan releases

Sida loo rakibo

  1. Taabo badhanka sare. Faylka waa .apk — ha furin ZIP.
  2. Marka Android weydiiyo, oggolow Install unknown apps app-ka faylka furaya (Settings → Apps → Special access).
  3. Taabo Install. Rakibadu waxay qaadataa ilbiriqsiyo.

“App not installed as package appears to be invalid”?

Fariintan waxaa soo saaray installer-ka Android, ma aha app-ka. Saddex wax ayaa caadi ahaan hagaajiya:

  1. Ka saar Babelish-kii hore (Settings → Apps → Babelish → Uninstall), kadib mar kale rakib.
  2. Mar kale soo deji — download aan dhammaad lahayn waa sababta ugu badan; faylku waa ~47 MB.
  3. Fur faylka Chrome ama Files app-ka, ma aha app kale oo ZIP u malaynaya.

SHA-256-ga faylka la daabacay waxaa laga helaa release-ka (babelish.apk.sha256). Haddii aad computer haysato: sha256sum babelish.apk.

English summary

Babelish 3.4.1 is a native-only Android and iPhone language-learning app. This page is not a web app: it is a static download and legal-information page only.

Android users can download the tested direct-install APK straight from the release link above (an APK file, not a ZIP); if Android says the package is invalid, uninstall an older copy, download again, and open the file from Chrome or the Files app. A physical iPhone install is not available yet; it requires the Apple Developer Program ($99/year) plus TestFlight or the App Store. The existing iOS artifact is an unsigned simulator build and cannot be installed on a physical iPhone.
